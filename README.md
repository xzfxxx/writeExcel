# writeExcel — 用 txt 里的 JSON 数据填充 Excel 模板

指定一个本地 Excel 模板（`.xlsx` / `.xlsm`），再给一个 txt 文件传入 JSON 数据，
程序会把内容按「行-列」坐标写进模板，另存为新文件。**模板原有的样式、列宽、合并单元格、冻结窗格都会保留。**

数据文件内容示例（位置 `l` 是 `行-列`，从 0 开始；`v` 是内容）：

```
[{l:'0-0',v:'内容1'},{l:'0-1',v:'内容2'}]
```

`0-0` 就是 Excel 的 `A1`。写出去以后模板样式不变，只填内容。

## 一、快速开始

### 方式 A：白板 Windows 电脑（不需要装 Python）

拿到 **`writeExcel.exe`** 这一个文件后，三种用法任选：

| 用法 | 操作 |
|------|------|
| ① 拖拽 | 把 **Excel 模板** 和 **数据 txt** 一起选中，拖到 `writeExcel.exe` 图标上松手 |
| ② 双击 | 双击 `writeExcel.exe`，按提示粘贴/拖入两个文件路径，回车 |
| ③ 命令行 | `writeExcel.exe 模板.xlsx 数据.txt` |

输出默认生成在同目录：`模板名_已填充.xlsx`。

### 方式 B：本机已装 Python

```bash
pip install -r requirements.txt          # 只需 openpyxl
python write_excel.py 模板.xlsx 数据.txt
```

Windows 上也可以双击 **`run.bat`** 进入交互模式。

## 三、数据 txt 怎么写

### 3.1 基本结构

顶层必须是一个数组，每个元素是一条 `{l:..., v:...}`：

```
[
  {l:'0-0', v:'张三'},
  {l:'0-1', v:'13800000000'},
  {l:'1-0', v:'李四'}
]
```

| 字段 | 含义 | 说明 |
|------|------|------|
| `l` | 位置 | `行-列`，**行列都从 0 开始**，`0-0` = A1 |
| `v` | 内容 | 字符串、数字、true/false 都行；写 `null` 表示清空该单元格 |

字段名的其他可用写法（选一个即可，大小写不敏感）：

- 位置：`l`、`loc`、`cell`、`pos`、`位置`、`坐标`、`单元格`
- 内容：`v`、`val`、`value`、`内容`、`值`、`文本`
- 工作表（可选）：`s`、`sheet`、`工作表`

### 3.2 位置写法

| 写法 | 含义 |
|------|------|
| `0-0` | 第 1 行第 1 列（A1） |
| `2-3` | 第 3 行第 4 列（D3） |
| `A1` | 也可以用 Excel 的 A1 写法（**行从 1 开始**） |
| `0-0,0-1` | 一次写两个单元格（同为 `l`，用逗号/分号/空格分隔） |
| `0-0:2-3` 或 `A1:D3` | 区域：同样的内容写进区域里每个单元格 |

> 注意：`0-0` 是「从 0 开始」的行列；`A1` 是「从 1 开始」的 Excel 写法，两种不要混用。

### 3.3 多工作表

默认写入活动工作表，可以用 `-s` 参数指定，也可以每条数据单独指定：

```
[
  {l:'0-0', v:'主表内容'},
  {l:'0-0', v:'副表内容', s:'说明'}
]
```

`-s` 后面可以写表名，也可以写序号（从 1 开始，`-s 2` 表示第二张表）。

### 3.4 容错：这些写法都能认

程序刻意做得比标准 JSON 宽松，手写数据时不必纠结：

| 情况 | 写法 | 是否支持 |
|------|------|----------|
| 单引号 | `{l:'0-0',v:'内容'}` | ✅ |
| 键名不加引号 | `{l:'0-0',v:内容}` | ✅ |
| 漏写冒号 | `{l'0-1',v:'内容2'}` | ✅ |
| 漏写逗号 | `{l:'0-0' v:'内容1'}` | ✅ |
| 结尾多余逗号 | `[{...},]` | ✅ |
| 中文全角标点 | `［｛l：“0-0”，v：“内容”｝］` | ✅ |
| 中文引号 | `{l:“0-0”, v:“内容”}` | ✅ |
| 注释 | `// 说明`、`/* 说明 */` | ✅ |
| 整体被引号包住 | `"[{l:'0-0',v:'内容'}]"` | ✅（自动去掉外层引号） |
| 外层带 data 包装 | `{data:[{l:'0-0',v:'内容'}]}` | ✅ |
| 字符串里的中文逗号 | `v:'内容，测试'` | ✅（不会拆开） |

### 3.5 编码

UTF-8、UTF-8(带 BOM)、GBK/GB18030、UTF-16 都会自动识别（记事本默认的编码也支持）。
如果识别错了，可以用 `--encoding gbk` 强制指定。

### 3.6 完整示例

见 `example/数据示例.txt`：

```
[
  // 位置写法：'行-列'，从 0 开始（0-0 就是 Excel 的 A1）
  {l:'2-0', v:'张三'},
  {l:'2-1', v:'13800000000'},
  {l:'2-2', v:'示例科技有限公司'},
  {l:'2-3', v:'重点客户，下周一回访'}
]
```

对应的成品模板是 `example/模板示例.xlsx`（带标题、表头、边框、列宽、冻结窗格），
运行 `python example/make_sample.py` 可重新生成。

## 四、命令行参数

```
write_excel.exe 模板.xlsx 数据.txt [输出.xlsx] [选项]
```

| 参数 | 说明 |
|------|------|
| `-t, --template` | Excel 模板路径 |
| `-d, --data` | 数据 txt 路径 |
| `-o, --output` | 输出路径（默认 `模板名_已填充.xlsx`；已存在时自动加 `(2)`） |
| `-s, --sheet` | 工作表名称或序号（从 1 开始） |
| `-y, --overwrite` | 允许覆盖已存在的文件；输出路径等于模板时视为「直接改模板」 |
| `--parse-numbers` | 把「纯数字字符串」写成数字（`'123'` → 123），`001` 这类仍保留文本 |
| `--force-text` | 全部写成文本，避免被识别成数字/日期 |
| `-n, --dry-run` | 只校验并打印将要写入的位置，不产生文件 |
| `--no-verify` | 保存后不再重新打开核对 |
| `--encoding` | 强制指定 txt 编码 |
| `--no-pause` | 结束时不等待回车（批处理用） |

位置参数也可以直接写：`write_excel.exe 模板.xlsx 数据.txt 结果.xlsx`。

### 交互模式

不带任何参数运行（或双击 `run.bat` / `writeExcel.exe`）会进入交互模式：

```
Excel 模板路径：  ← 可以把文件直接拖进窗口
数据 txt 路径：
输出文件（回车使用默认：模板_已填充.xlsx）：
```

## 五、常见问题

**Q：会破坏模板的样式吗？**
不会。程序只改单元格的值，表格样式、列宽、行高、边框、合并单元格、冻结窗格、数据验证等都保留（已由自动测试覆盖）。

**Q：模板里有图片/图表/批注？**
openpyxl 保存时可能丢掉图片、图表、批注（这是库的限制，程序检测到会给出提示）。如果模板必须有图片/图表，建议：把图片/图表放在另一张表，或先填数据再把图片贴回去，或者用 Excel 宏处理。

**Q：内容以 `=` 开头？**
会被 Excel 当成公式写入（程序会提示）。如果只想写文本，避免以 `=` 开头。

**Q：写了合并单元格里的位置？**
内容会写到合并区域的左上角单元格（程序会提示具体是哪个格子）。

**Q：提示「文件正在被 Excel 打开」？**
关掉 Excel 里打开的那个文件再运行。

**Q：中文是乱码？**
txt 保存时用 UTF-8 或 GBK 均可（程序会自动识别）；若识别错可加 `--encoding gbk`。

**Q：单个单元格内容太长？**
Excel 上限 32767 个字符，超了会报错并说明是哪一条。

**Q：支持 `.xls`（2003 旧格式）吗？**
不支持。用 Excel 打开后「另存为」→ Excel 工作簿 `(*.xlsx)` 再用。

**Q：exe 被杀毒软件/SmartScreen 拦截？**
未签名的小程序偶尔会触发。点「更多信息」→「仍要运行」即可；也可以在企业白名单里放行。

**Q：输出文件名重复怎么办？**
默认自动加 `(2)`、`(3)`；想覆盖就加 `-y`。

## 八、已知限制

- 只支持 `.xlsx` / `.xlsm`；`.xls`、`.xltx` 需要先另存。
- 依赖 openpyxl 的能力边界：图片、图表、批注可能在保存后丢失（会提示）。
- 不支持给单元格单独设字体/颜色（样式由模板决定）；如需按内容变色，可在模板里用「条件格式」。
- 定位是「固定坐标」模式：每条数据必须明确给出 `行-列`，不会自动追加行。
