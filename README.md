# writeExcel — 用 txt 里的 JSON 数据填充 Excel 模板

指定一个本地 Excel 模板（`.xlsx` / `.xlsm`），再给一个 txt 文件传入 JSON 数据，
程序会把内容按「行-列」坐标写进模板，另存为新文件。**模板原有的样式、列宽、合并单元格、冻结窗格都会保留。**

数据文件内容示例（位置 `l` 是 `行-列`，从 0 开始；`v` 是内容）：

```
[{l:'0-0',v:'内容1'},{l:'0-1',v:'内容2'}]
```

`0-0` 就是 Excel 的 `A1`。写出去以后模板样式不变，只填内容。

## 一、快速开始

### 方式 A：白板 Windows 电脑（不需要装 Python）

拿到 **`writeExcel.exe`** 这一个文件后，三种用法任选：

| 用法 | 操作 |
|------|------|
| ① 拖拽 | 把 **Excel 模板** 和 **数据 txt** 一起选中，拖到 `writeExcel.exe` 图标上松手 |
| ② 双击 | 双击 `writeExcel.exe`，按提示粘贴/拖入两个文件路径，回车 |
| ③ 命令行 | `writeExcel.exe 模板.xlsx 数据.txt` |
| ④ 脚本自动调用 | `fill.bat 模板.xlsx 数据.txt [输出.xlsx]`（全程无人工交互，见第五节） |

输出默认生成在模板同目录：`模板名_已填充.xlsx`。

### 方式 B：本机已装 Python

```bash
pip install -r requirements.txt          # 只需 openpyxl
python write_excel.py 模板.xlsx 数据.txt
```

Windows 上也可以双击 **`run.bat`** 进入交互模式。

## 三、数据 txt 怎么写

### 3.1 基本结构

数据有两种写法，任选其一：

* **写法一：普通数组**（写进活动工作表 / `-s` 指定的工作表）
* **写法二：按工作表分组**（见 3.4，可按参数重命名工作表页签）

**写法一**的顶层是一个数组，每个元素是一条 `{l:..., v:...}`：

```
[
  {l:'0-0', v:'张三'},
  {l:'0-1', v:'13800000000'},
  {l:'1-0', v:'李四'}
]
```

| 字段 | 含义 | 说明 |
|------|------|------|
| `l` | 位置 | `行-列`，**行列都从 0 开始**，`0-0` = A1 |
| `v` | 内容 | 字符串、数字、true/false 都行；写 `null` 表示清空该单元格 |

字段名的其他可用写法（选一个即可，大小写不敏感）：

- 位置：`l`、`loc`、`cell`、`pos`、`位置`、`坐标`、`单元格`
- 内容：`v`、`val`、`value`、`内容`、`值`、`文本`
- 工作表（可选）：`s`、`sheet`、`工作表`

### 3.2 位置写法

| 写法 | 含义 |
|------|------|
| `0-0` | 第 1 行第 1 列（A1） |
| `2-3` | 第 3 行第 4 列（D3） |
| `A1` | 也可以用 Excel 的 A1 写法（**行从 1 开始**） |
| `0-0,0-1` | 一次写两个单元格（同为 `l`，用逗号/分号/空格分隔） |
| `0-0:2-3` 或 `A1:D3` | 区域：同样的内容写进区域里每个单元格 |

> 注意：`0-0` 是「从 0 开始」的行列；`A1` 是「从 1 开始」的 Excel 写法，两种不要混用。

### 3.3 多工作表

默认写入活动工作表，可以用 `-s` 参数指定，也可以每条数据单独指定：

```
[
  {l:'0-0', v:'主表内容'},
  {l:'0-0', v:'副表内容', s:'说明'}
]
```

`-s` 后面可以写表名，也可以写序号（从 1 开始，`-s 2` 表示第二张表）。

### 3.4 按工作表分组（可同时重命名工作表）

顶层写成「工作表名 → 该表的内容」的对象，分组名会用来**重命名模板里的工作表页签**：

```
{
  '客户清单': [
    {l:'2-0', v:'张三'},
    {l:'2-1', v:'13800000000'}
  ],
  '备注表': {}          // 空 {} 或 [] 表示只改表名、不写内容
}
```

**对应规则**（按顺序判断）：

1. 分组名与模板中的工作表**同名**（忽略大小写和首尾空格）→ 直接用那张表，并把页签改成你写的名字（仅大小写/空格不同也算）；
2. 否则，如果**分组数量 == 模板工作表数量** → 按顺序一一对应（第 1 个分组 → 第 1 张表，依此类推）；
3. 都不满足 → 报错，并列出模板里有哪些工作表，方便你改名对齐。

注意：

* 分组里的值可以是一条 `{l,v}`、也可以是一个数组 `[{...},{...}]`、或者空 `{}` / `[]`；
* 分组格式下，条目里再写 `s:'xxx'` 会被忽略（有提示），用 `-s` 参数也会被忽略（有提示）；
* 工作表名限制：≤31 个字符，不能含 `: \ / ? * [ ]`；
* 想把页签改成「数据和模板不同」的名字时，直接把它写成分组名即可，例如模板里的 `Sheet1` 想变成 `销售明细`，就写 `{'销售明细': [...]}`。

示例数据：`example/数据示例_多表.txt`（配合 `example/模板示例.xlsx`，会把「客户信息」「备注说明」两张表改名为「客户清单」「备注表」）。

### 3.5 容错：这些写法都能认

程序刻意做得比标准 JSON 宽松，手写数据时不必纠结：

| 情况 | 写法 | 是否支持 |
|------|------|----------|
| 单引号 | `{l:'0-0',v:'内容'}` | ✅ |
| 键名不加引号 | `{l:'0-0',v:内容}` | ✅ |
| 漏写冒号 | `{l'0-1',v:'内容2'}` | ✅ |
| 漏写逗号 | `{l:'0-0' v:'内容1'}` | ✅ |
| 结尾多余逗号 | `[{...},]` | ✅ |
| 中文全角标点 | `［｛l：“0-0”，v：“内容”｝］` | ✅ |
| 中文引号 | `{l:“0-0”, v:“内容”}` | ✅ |
| 注释 | `// 说明`、`/* 说明 */` | ✅ |
| 整体被引号包住 | `"[{l:'0-0',v:'内容'}]"` | ✅（自动去掉外层引号） |
| 外层带 data 包装 | `{data:[{l:'0-0',v:'内容'}]}` | ✅ |
| 字符串里的中文逗号 | `v:'内容，测试'` | ✅（不会拆开） |

### 3.6 编码

UTF-8、UTF-8(带 BOM)、GBK/GB18030、UTF-16 都会自动识别（记事本默认的编码也支持）。
如果识别错了，可以用 `--encoding gbk` 强制指定。

### 3.7 完整示例

见 `example/数据示例.txt`：

```
[
  // 位置写法：'行-列'，从 0 开始（0-0 就是 Excel 的 A1）
  {l:'2-0', v:'张三'},
  {l:'2-1', v:'13800000000'},
  {l:'2-2', v:'示例科技有限公司'},
  {l:'2-3', v:'重点客户，下周一回访'}
]
```

对应的成品模板是 `example/模板示例.xlsx`（带标题、表头、边框、列宽、冻结窗格），
运行 `python example/make_sample.py` 可重新生成。

## 四、命令行参数

```
write_excel.exe 模板.xlsx 数据.txt [输出.xlsx] [选项]
```

| 参数 | 说明 |
|------|------|
| `-t, --template` | Excel 模板路径 |
| `-d, --data` | 数据 txt 路径 |
| `-o, --output` | 输出路径（默认 `模板名_已填充.xlsx`；已存在时自动加 `(2)`） |
| `-s, --sheet` | 工作表名称或序号（从 1 开始） |
| `-y, --overwrite` | 允许覆盖已存在的文件；输出路径等于模板时视为「直接改模板」 |
| `--parse-numbers` | 把「纯数字字符串」写成数字（`'123'` → 123），`001` 这类仍保留文本 |
| `--force-text` | 全部写成文本，避免被识别成数字/日期 |
| `-n, --dry-run` | 只校验并打印将要写入的位置，不产生文件 |
| `--no-verify` | 保存后不再重新打开核对 |
| `--encoding` | 强制指定 txt 编码 |
| `--pause` | 结束后等待回车（默认只有不带参数双击时才等待；脚本里一般不需要） |
| `--no-pause` | 强制不等待回车（供脚本安全调用） |

位置参数也可以直接写：`write_excel.exe 模板.xlsx 数据.txt 结果.xlsx`。

> **是否暂停**：带参数调用（bat / 自动化）**默认不暂停、执行完立即退出**；不带参数双击时才会暂停等你按键。表里「无参数调用」部分同样适用。

### 交互模式

不带任何参数运行（或双击 `run.bat` / `writeExcel.exe`）会进入交互模式：

```
Excel 模板路径：  ← 可以把文件直接拖进窗口
数据 txt 路径：
输出文件（回车使用默认：模板_已填充.xlsx）：
```

## 五、用 bat 脚本自动调用（无人工交互）

把 `writeExcel.exe` 和 `fill.bat` 放在**同一个文件夹**，然后在自己的脚本 / 程序里调用：

```bat
fill.bat 模板.xlsx 数据.txt [输出.xlsx] [更多参数...]
```

| 位置 | 含义 |
|------|------|
| 参数1 | Excel 模板路径（必填） |
| 参数2 | 数据 txt 路径（必填） |
| 参数3 | 输出文件名或完整路径（**不传** → 按原逻辑生成 `模板名_已填充.xlsx`，已存在自动加 `(2)`） |
| 参数4+ | 透传给程序，例如 `-y`（覆盖）、`--parse-numbers`、`--force-text` |

> 参数3 如果只写文件名（不带目录），文件会生成在**调用时的当前目录**；建议需要固定位置时直接传完整路径。

特点：

* **全程不需要人工操作**，执行完立即返回，不会停在窗口等回车；
* 用 **退出码** 判断结果：`0` = 成功，`2` = 参数不对，`3` = 数据有问题，`4` = 写入失败，`9009` = 找不到 exe；
* 标准的 Windows 批处理调用方式，可被 Python / Java / .NET / 计划任务 / Web 后端直接调用。

示例（生成到指定目录，允许覆盖）：

```bat
fill.bat "D:\模板\客户模板.xlsx" "D:\数据\data.txt" "D:\输出\客户结果.xlsx" -y
```

只想验证整条链路是否正常，可以双击 **`demo_auto.bat`**：它会自动用示例模板 + 多表示例数据生成 `example\自动输出.xlsx` 并显示退出码。

> 如果直接在代码里调用 `writeExcel.exe`（不经过 fill.bat），请注意带上 `--no-pause`（虽然带参数调用默认也不暂停，加上更保险），并用退出码判断成败。

## 六、常见问题

**Q：会破坏模板的样式吗？**
不会。程序只改单元格的值，表格样式、列宽、行高、边框、合并单元格、冻结窗格、数据验证等都保留（已由自动测试覆盖）。

**Q：模板里有图片/图表/批注？**
openpyxl 保存时可能丢掉图片、图表、批注（这是库的限制，程序检测到会给出提示）。如果模板必须有图片/图表，建议：把图片/图表放在另一张表，或先填数据再把图片贴回去，或者用 Excel 宏处理。

**Q：内容以 `=` 开头？**
会被 Excel 当成公式写入（程序会提示）。如果只想写文本，避免以 `=` 开头。

**Q：写了合并单元格里的位置？**
内容会写到合并区域的左上角单元格（程序会提示具体是哪个格子）。

**Q：提示「文件正在被 Excel 打开」？**
关掉 Excel 里打开的那个文件再运行。

**Q：中文是乱码？**
txt 保存时用 UTF-8 或 GBK 均可（程序会自动识别）；若识别错可加 `--encoding gbk`。

**Q：单个单元格内容太长？**
Excel 上限 32767 个字符，超了会报错并说明是哪一条。

**Q：支持 `.xls`（2003 旧格式）吗？**
不支持。用 Excel 打开后「另存为」→ Excel 工作簿 `(*.xlsx)` 再用。

**Q：exe 被杀毒软件/SmartScreen 拦截？**
未签名的小程序偶尔会触发。点「更多信息」→「仍要运行」即可；也可以在企业白名单里放行。

**Q：输出文件名重复怎么办？**
默认自动加 `(2)`、`(3)`；想覆盖就加 `-y`。

**Q：按工作表分组时报「分组数对不上」？**
分组数必须与模板工作表数相等（按顺序对应），或者每个分组名都与模板里的表名一致（按名字对应）。报错信息里会列出模板现有的工作表名，照着改即可。

**Q：想改工作表的页签名字？**
用分组写法把新名字写成 key 即可：`{'新表名': [...]}`（见 3.4）。

**Q：bat 调用后窗口一闪而过 / 没看到结果？**
这是预期行为：带参数调用不暂停。看退出码（`%ERRORLEVEL%`）或用 `--pause` 让它停下来。

**Q：一个工作表都没有、只想改名？**
分组值写空对象 `{}` 或空数组 `[]`，例如 `{'2024年数据': {}}`，只会重命名页签。

## 九、已知限制

- 只支持 `.xlsx` / `.xlsm`；`.xls`、`.xltx` 需要先另存。
- 依赖 openpyxl 的能力边界：图片、图表、批注可能在保存后丢失（会提示）。
- 不支持给单元格单独设字体/颜色（样式由模板决定）；如需按内容变色，可在模板里用「条件格式」。
- 定位是「固定坐标」模式：每条数据必须明确给出 `行-列`，不会自动追加行。
- 按工作表分组时只支持「与模板同名对应」或「按顺序对应」两种匹配方式，不做模糊猜测。
- 重命名工作表会改变页签名字，但不会改变页签顺序。
